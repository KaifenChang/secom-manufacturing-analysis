# SECOM Manufacturing Fault Detection & Feature Selection

#### Overview             
This project applies machine learning techniques for fault detection in semiconductor manufacturing using sensor data. We analyze feature importance using Random Forest and XGBoost, train classification models, and compare their performance.

#### Data
This project uses the SECOM dataset from the UCI Machine Learning Repository:
McCann, M. & Johnston, A. (2008). SECOM [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C54305.

The SECOM dataset contains 1567 examples with 591 features.

#### Key Features
- Feature selection using Random Forest and XGBoost 
- Classification using Random Forest and XGBoost
- Performance evaluation using ROC curve and F1 score
